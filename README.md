# PrecisionTimer

PrecisionTimer is a simple stopwatch web application that displays time in minutes and seconds.

## Features

- Start and reset the stopwatch
- Display time in `MM:SS` format
- Clean and responsive design

## Technologies Used

- HTML
- Bootstrap
- JavaScript

## How to Run

Download the project files and open `index.html` in your browser.

## Project Files

- `index.html` – Contains the webpage structure and design
- `app.js` – Contains the stopwatch functionality
- `README.md` – Contains project information
